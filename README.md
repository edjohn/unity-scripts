# unity-scripts
A temporary repository for two games in C# using the Unity API

Block-Breaker: A game based on Breakout (Atari 2600)
Laser-Defender: A game based on Galaxian (Atari 2600)

Many of these scripts have dependencies upon other asset files such as sprites and soundbytes. Scripts last edited in Unity Version 2019.1.5f1, so may not be compatible with recent iterations.
